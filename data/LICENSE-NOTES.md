# Data attribution and reuse

These CSV files were exported without changing the counts from the Bioconductor airway package (Michael Love; version and SHA-256 in manifest.json). The upstream package declares LGPL; this project preserves that designation and does not relicense these data under the project code license.
Upstream source and license declaration: https://bioconductor.org/packages/airway
Experiment: Himes BE et al. (2014), PLOS ONE 9(6):e99625, https://doi.org/10.1371/journal.pone.0099625
The original article states Creative Commons Attribution licensing, requiring author/source credit.
GEO accession: GSE52778. Only four control/dexamethasone pairs without albuterol were exported.
Annotation is Ensembl 75 / GRCh37.p13 as carried by airway, not newly acquired annotation.
No upstream executable code was copied into this repository. Preserve this attribution and manifest with redistributed CSVs; consult upstream terms for uses beyond this demonstrative reanalysis.
